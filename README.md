# ☕ 모두의 음료 (Cafe Order Collector)

> **단체 음료 주문을 받을 때 메뉴별 수량을 자동으로 세어주고, 카페별 맞춤 메뉴판과 카톡 복붙 자동 집계를 제공하는 스마트 주문 도우미 웹앱**

---

## 🌟 주요 기능

1. **카페별 맞춤 메뉴판 & 자유로운 커스텀**
   - 대표 프랜차이즈 프리셋 기본 탑재 (스타벅스, 메가커피, 컴포즈커피, 빽다방, 투썸플레이스)
   - 새로운 카페 추가, 메뉴 추가/삭제/가격 수정 지원
   - 모든 데이터는 브라우저(`localStorage`)에 자동 저장되어 영구 보존

2. **단톡방 대화 텍스트 스마트 자동 집계 (복사-붙여넣기)**
   - 카톡이나 사내 메신저 주문 대화를 그대로 복사해서 붙여넣으면 자동 분석
   - 일상 줄임말 자동 인식:
     - `아아`, `아.아`, `차아` ➜ 아이스 아메리카노
     - `뜨아`, `따아`, `핫아` ➜ 따뜻한 아메리카노
     - `뜨라`, `아라`, `바라`, `아바라`, `자허블`, `바크콜`, `딸쿠프` 등
   - 옵션(연하게, 샷추가, 덜달게, 디카페인, 오트밀크 등) 및 수량(2잔, 3개 등) 자동 파싱
   - 주문자 명단 및 메뉴별 합계 수량 원클릭 자동 카운팅

3. **원터치 포스(POS)형 터치 카운터**
   - 카테고리별(에스프레소, 콜드브루, 티/스무디 등) 필터링
   - ICE / HOT 원터치 전환 및 + / - 버튼으로 신속한 카운팅
   - 메뉴판에 없는 음료도 하단 `[+ 직접 추가]`로 즉시 반영

4. **현장 주문 전용 편의 기능**
   - **대형 폰트 카운터 주문서**: 키오스크나 카페 직원 앞에서 한눈에 보기 편한 큼직한 요약 뷰
   - **카카오톡 공유 텍스트 원클릭 복사**: 단톡방에 주문 완료 공지를 깔끔한 텍스트로 즉시 전송
   - **1/N 더치페이 정산기**: 총 금액과 인원수를 넣으면 1인당 금액 자동 계산 및 정산 텍스트 복사

## 💻 실행 방법

### 방법 1: `start.bat` 더블 클릭 (PC 브라우저 즉시 열기)
`cafe-order` 폴더 내의 `start.bat`을 더블 클릭하면 기본 웹 브라우저에서 바로 열립니다.

### 방법 2: `run_mobile.bat` 더블 클릭 (스마트폰 무선 연동)
`run_mobile.bat`을 실행하면 PC 화면에 **스마트폰 접속용 주소(예: http://192.168.0.11:8080)**가 표시됩니다.
스마트폰이 같은 Wi-Fi에 연결되어 있다면 스마트폰 웹 브라우저로 접속하여 바로 사용할 수 있습니다!

### 방법 3: `index.html` 직접 더블 클릭
`cafe-order/index.html` 파일을 크롬, 엣지, 웨일 등 브라우저로 직접 엽니다.

---

### 📱 스마트폰 홈 화면에 진짜 앱처럼 설치하는 법
1. 스마트폰 브라우저(Safari, Chrome, 삼성 인터넷 등)로 접속합니다.
2. 브라우저 하단 공유/메뉴 버튼에서 **[홈 화면에 추가]** 또는 **[앱 설치]**를 누릅니다.
3. 스마트폰 바탕화면에 **☕ 모두의 음료** 아이콘이 생성되어, 언제든 진짜 모바일 앱처럼 탭해서 바로 실행할 수 있습니다.
